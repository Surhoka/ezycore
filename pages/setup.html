Database legacy tidak ditemukan di Google Drive.

EzyCore akan menginisialisasi sistem dengan Firestore:

  • Firestore collection _config/global untuk konfigurasi sistem
  • Firestore collection Users untuk autentikasi Firebase Auth
  • Firestore collection Profile untuk data pengguna
  • Folder Images di Google Drive untuk penyimpanan file
  • Upload Firebase JSON (service account) untuk akses Firestore & Auth
